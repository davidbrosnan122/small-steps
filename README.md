# Small Steps

A small task-list web app built with HTML, CSS, and JavaScript. Add tasks, mark them complete, and delete them. Tasks stay in the same browser using localStorage.

## Run

Download this repository and open `index.html` in a modern browser. No dependencies or build step are needed. For a consistent local origin, serve the folder with any static web server.

## Features

- Responsive layout and keyboard-accessible controls
- Remaining-task count
- Local saving across page reloads
- Plain-text task rendering
- A warning if browser storage is unavailable

## Limits

Tasks do not sync between devices or browsers. Clearing browser storage removes saved tasks. This is a starter project, not a production task-management service.
